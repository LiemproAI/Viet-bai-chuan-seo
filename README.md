# Viết bài chuẩn SEO

Bài viết tiếng Việt về hành trình con đi học tại Mỹ, cùng skill SEO Blog Writer dùng để viết và biên tập nội dung.

## Nội dung

- `index.html`: trang chủ, bố cục thích ứng điện thoại, hình minh họa SVG tích hợp trong file.
- `hanh-trinh-cua-con.html`: bản bài viết với tên riêng, cùng nội dung trang chủ.
- `seo-blog-writer/`: bộ skill, hướng dẫn sử dụng, cấu hình giao diện và tài nguyên gốc.

Mở `index.html` bằng trình duyệt để xem tại máy. Không cần cài thư viện hoặc chạy build.

## Đưa website lên mạng bằng GitHub Pages

Trong repo GitHub, mở **Settings → Pages**, chọn **Deploy from a branch**, chọn nhánh `main` và thư mục `/ (root)`, rồi **Save**.

Sau khi GitHub triển khai, dùng địa chỉ website được hiển thị trong mục Pages. Để kết nối `doanchiliem.pro.vn`, cấu hình **Custom domain** và DNS theo hướng dẫn GitHub Pages. Repo này chưa tự cấu hình DNS hay domain.
